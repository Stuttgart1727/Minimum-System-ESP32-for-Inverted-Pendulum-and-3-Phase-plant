# Minimum-System-ESP32-for-Inverted-Pendulum-and-3-Phase-plant
Design and documentation of minimum system schematics for an Inverted Pendulum Plant and a 3-Phase AC System, including electronic circuits, hardware interfaces, and supporting components for control and monitoring applications.
Overview
This repository contains the schematic design of the minimum system for two engineering applications:
1.	Inverted Pendulum Plant – An electronic control system designed to support the operation and control of an inverted pendulum plant.
2.	3-Phase AC System – A minimum system schematic designed for interfacing with and monitoring a three-phase alternating current (AC) system.
The project focuses on designing the essential electronic circuits, hardware interfaces, and supporting components required for system operation and integration with a control system.
 Project Objectives
•	Design the minimum system schematic for an inverted pendulum plant.
•	Design the minimum system schematic for a 3-phase AC system.
•	Identify the essential electronic components and their connections.
•	Provide a hardware reference for future PCB development and system integration.
•	Support the implementation of control, monitoring, and measurement systems.

 System Description
1. Inverted Pendulum Plant
The inverted pendulum system is an experimental control plant used to study dynamic system behavior, stability, and control algorithms.
The minimum system schematic covers the essential electronic hardware required to interface with the plant's sensors, actuators, and main controller.
Main considerations:
•	Controller interface.
•	Sensor signal conditioning.
•	Motor driver interface.
•	Encoder Analyzer
•	Angular Detection.
2. 3-Phase AC System
The three-phase AC system is designed as an electronic interface for a three-phase electrical system.
The schematic focuses on the essential hardware needed for signal acquisition, voltage/current measurement interfaces, and system monitoring.
Main considerations:
•	Three-phase voltage sensing.
•	Voltage sensing interface.
•	Signal conditioning and isolation.
•	Controller interface.
•	DAC to Inverter.
•	Electrical protection and safety.
 Design Tools
The schematics are developed using electronic design automation (EDA) tools.
•	Schematic design.
•	Electronic component selection.
•	Circuit connectivity documentation.
•	Hardware interface planning.
 Safety Notes
The 3-phase AC system involves potentially hazardous electrical voltages and currents.
•	Always use appropriate electrical isolation.
•	Include proper fuses and circuit protection.
•	Verify component voltage and current ratings.
•	Follow applicable electrical safety standards.
•	Do not connect the circuit directly to a live three-phase power source without proper isolation and protection.
